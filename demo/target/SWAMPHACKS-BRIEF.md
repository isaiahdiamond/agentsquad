# SwampHacks redesign

Build a complete, responsive redesign of https://xii.swamphacks.com/ in this project's React app. This is a local design concept, not the official event website.

Use scout to inspect the existing code and official event content, frontend-dev to build the experience, and test-engineer to verify the important interactions and production build. Delegate to the deployed specialists so the work appears in AgentViz.

Creative direction: a nocturnal Florida field journal. Deep pine background, acid-lime typography, warm cream panels, oversized editorial headings, subtle topographic lines, and a distinctive illustrated swamp scene. Avoid a generic collection of gradient cards. Make the mobile experience as considered as desktop, respect reduced motion, and provide visible keyboard focus.

Use verified event facts: SwampHacks XII, October 16–18, 2026, Reitz Union at the University of Florida, 36 hours. The reference describes 400+ hackers, 10+ workshops, 100+ projects, and $10k+ in prizes. Do not invent sponsors, scheduled sessions, application deadlines, or future dates. Since the event is underway, avoid a countdown to a date that has already passed. Link applications or event resources to the real official destinations after inspecting them.

Include a memorable hero, event facts, about section, tracks, FAQ accordion, sponsorship/contact section, and footer. Label any unverified schedule as illustrative or omit it. Navigation and buttons must work; do not create a fake signup form. Clearly label the result as an unofficial redesign concept.

Replace the starter todo interface. Update any obsolete starter tests, test navigation and FAQ behavior, run npm test and npm run build, and fix failures. Start the resulting site on port 5174, leaving AgentViz on port 5173. Report the preview URL and changed files.
